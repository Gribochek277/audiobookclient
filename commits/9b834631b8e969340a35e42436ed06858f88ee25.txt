M3+M4: local cache + sync engine with conflict resolution
M3 cache.rs:
- on-demand download, atomic (file.partial + rename) — an interrupted
  download never masquerades as a finished file
- cache status / clean --finished / clean --all, stale .partial removal

M4 sync.rs (pure engine, resolver injected) + store.rs (SQLite local store):
- per-book model: shared file version (base_updated_at) + local dirtiness
  (dirty_since); device-local fields never leave the local SQLite
- push  = dirty + shared file untouched since base
- pull  = clean + remote differs
- conflict = dirty + file changed since base -> Device/Server prompt
- book deleted from NAS -> reported missing, local record kept; stale
  shared record dropped
- CLI: sync (dialoguer conflict prompt, client name = hostname),
  cache status/clean
- config: client_name() helper (hostname, fallback 'local')

tests: 42 lib + 3 integration (tests/sync_flow.rs runs the full
scan -> store -> sync -> write-back flow on a LocalDirTransport fake NAS)
