Help overlay: show the cache budget (usage vs limit_gb)
The cache size budget ([cache] limit_gb, default 10 GB, 0 = off) existed
but was invisible from the app, so users did not know it could be
configured. The help overlay now shows a live line under the library
section on both screens, e.g. 'cache 6.7 GB/10.0 GB ([cache] limit_gb,
0 = off)'. The line is computed when the overlay opens (a cache walk is
not per-frame work) via a provider closure attached by the TUI entry
point; tests and cache-less setups simply omit the line.
cache::budget_line formats both the limited and unlimited cases; 3 new
unit tests (1 cache, 2 TUI).
